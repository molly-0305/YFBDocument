（1）从控制面板-管理工具，打开你的 数据源(ODBC)，根据系统架构选择
<img src={require('@site/static/img/softwareInstall/WindowsOther/2/6.png').default} alt=""/><br /><br /> <br />

<img src={require('@site/static/img/softwareInstall/WindowsOther/2/7.png').default} alt=""/><br /><br /> <br />  

（3）完成后会出现MySQL 链接对话框，添加你的 MySQL 数据库账号信息，并确认"root"账号是否有全部的权限，如果你安装MySQL 没有修改的话， 不要改 3306这个端口号。  
如下图所示：
