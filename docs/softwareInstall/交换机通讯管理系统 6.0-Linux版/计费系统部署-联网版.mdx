### 5、连接Tidb数据库并初始化数据库
（1）连接TIDB服务
mysql -h tidb_db -P 4000 -uroot --default-character-set=utf8mb4
```
mysql -h tidb_db -P 4000 -uroot --default-character-set=utf8mb4
```
<img src={require('@site/static/img/softwareInstall/Networking/6.0/Bill/13.png').default} alt=""/>

（2）修改 root 用户的密码为 sa  
ALTER USER 'root'@'%' IDENTIFIED BY 'sa';
```
ALTER USER 'root'@'%' IDENTIFIED BY 'sa';
```
<br /><br />
刷新权限，使密码更改立即生效  
FLUSH PRIVILEGES;
```
FLUSH PRIVILEGES;
```

<br /><br />
退出数据库  
exit
```
exit
```
<img src={require('@site/static/img/softwareInstall/Networking/6.0/Bill/14.png').default} alt=""/>


（3）创建字符集设为utf8mb4的数据库  
mysql -h tidb_db -P 4000 -uroot -psa --default-character-set=utf8mb4 -e "CREATE DATABASE billcommonstandard DEFAULT CHARACTER SET utf8mb4;"
```
mysql -h tidb_db -P 4000 -uroot -psa --default-character-set=utf8mb4 -e "CREATE DATABASE billcommonstandard DEFAULT CHARACTER SET utf8mb4;"
```
