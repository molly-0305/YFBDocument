### 6、添加.Net3.5功能

<span class="red" style={{fontSize:"21px"}}>&emsp;SXS 文件夹包含了安装 .NET Framework 3.5 所需的所有文件，这些文件是从系统镜像中提取的原版文件，确保了安装过程的稳定性和兼容性。</span>

[sxs2019.zip](https://pan.baidu.com/s/1TE6jgwUXsO89pXSnqPE9WA)&emsp;&emsp;
[sxs2022.zip](https://pan.baidu.com/s/1YWGP1jDTi-BOD4vq_-2tbQ)
