## 一、Log In

Open the 'Switch Communication Management System WEB Query and Statistics' software, and it will automatically open the browser and enter the user login interface.  
Username: admin      
Password: 88888      
Click 'Login' to enter the web page     
ht&#8203;tps://127.0.0.1:6062/Login/IndexThis address is the billing server address      
Devices on the same local network can change the billing IP 127.0.0.1 to the IP address of the machine where the web server is installed to access it.      
For example：  
<span class="blue">ht&#8203;tps:/192.168.6.27:6062/Login/Index</span>    
<span class="blue">Username: admin</span>    
<span class="blue">Password: 88888</span>    
If other administrators are set up on the server, you can log in directly with the administrator account
