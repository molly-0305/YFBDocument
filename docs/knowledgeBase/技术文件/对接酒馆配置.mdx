### 1、通讯方式
支持：LAN或COM，端口参数可以随意配置。  
LAN口：推荐采用UDP通讯方式，酒管连接中间件的端口号：<span class="blue">2556</span>，中间件连接酒管的端口可自定义或跟随酒管进行修改。当然用TCP Client或TCP Server也可以，端口号均可自定义协商。  

### 2、话单输出
发送计费话单到酒管系统，ASCⅡ/UTF-8编码发送，格式支持自定义，比如发送哪些字段，字段占位，前后顺序都可以随酒管系统要求灵活配置。  
下面为参考样例：  
<span class="blue">T8118&nbsp;,2015-10-18&nbsp;&nbsp;,15:07:09&nbsp;&nbsp;&nbsp;,00:00:26&nbsp;&nbsp;,15312344321&nbsp;&nbsp;&nbsp;&nbsp;,00&nbsp;,0.200</span>  
<span class="blue">共60位，所有字段以英文逗号分隔。</span>  
话单开始符：T，占1位  
分机号码：占5位，以空格后补位  
通话日期：占12位，以空格后补位  
开始时间：占10位，以空格后补位  
通话时长：占10位，以空格后补位  
电话号码：占15位，以空格后补位  
话务类型：占3位，以空格后补位，00代表市话，01代表国内长途，03代表港澳台长途，04代表国际长途  
话费：占5位，以空格后补位  

### 3、入住Check In /退房 Check Out
酒管系统发送Check In / Check Out命令给中间件，我们再控制IPPBX，ASCⅡ/UTF-8编码也可以随酒管系统要求灵活配置。  
下面为参考样例：  
<span class="blue">入住：C&nbsp;1&nbsp;6001&nbsp;01&nbsp;yuehuixu&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;01&nbsp;1234567890</span>  
<span class="blue">退房：C&nbsp;0&nbsp;6001&nbsp;04&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;                                </span>  
共45位  
功能码：占2位，以空格后补位   
入住/退房：占2位，1代表入住，0代表退房，以空格后补位  
房间号码：占5位，以空格后补位，样例中的房间号码为6001  
分机等级：占3位，以空格后补位，01代表国际长途，02代表国内长途，03代表市话，04代表内线  
客人姓名：占20位，以空格后补位，样例中的yuehuixu  
语言：占3位，以空格后补位，01代表中文，02代表英文，03代表日文，04代表韩文  
团队号码：占10位，以空格后补位，样例中的团队号码为1234567890  
酒管发送指令后，如需回应返回值的话，我们可以返回：COK  

### 4、换房
下面为参考样例：  
<span class="blue">修改等级：E&nbsp;6001&nbsp;6002&nbsp;</span>  
共12位  
功能码：占2位，以空格后补位  
原房间号码：占5位，以空格后补位，样例中的房间号码为6001  
新房间号码：占5位，以空格后补位，样例中的房间号码为6002  
酒管发送指令后，如需回应返回值的话，我们可以返回：EOK

### 6、叫醒
酒管系统发送Morning Call叫醒命令给中间件，我们再控制IPPBX，ASCⅡ/UTF-8编码也可以随酒管系统要求灵活配置。  
下面为参考样例：  
<span class="blue">设置叫醒：M&nbsp;1&nbsp;6001&nbsp;1234567890yyyy-mm-dd&nbsp;HH:mm&nbsp;2&nbsp;</span>      
共38位  
功能码：占2位，以空格补位  
设置/取消叫醒：占2位，1代表设置，0代表取消，以空格后补位  
房间号码：占5位，以空格后补位，样例中的房间号码为6001  
团队号码：占10位，以空格后补位，样例中的团队号码为1234567890  
叫醒日期：占11位，yyyy-mm-dd，以空格后补位  
叫醒时间：占6位,HH:mm，以空格后补位  
重复次数：占2位，以空格后补位  
酒管发送指令后，如需回应返回值的话，我们可以返回：MOK  

叫醒后中间件系统会把叫醒结果返回给酒管系统。  
返回叫醒结果：<span class="blue">N&nbsp;6001&nbsp;yyyy-mm-dd&nbsp;HH:mm&nbsp;false</span>  
共29位   
功能码：占2位，以空格后补位  
房间号码：占5位，以空格后补位，样例中的房间号码为6001  
叫醒日期：占11位，yyyy-mm-dd，以空格后补位  
叫醒时间：占6位,HH:mm，以空格后补位  
叫醒结果：占5位，以空格后补位，叫醒已接成功为true，叫醒未接失败为false  
酒管发送指令后，如需回应返回值的话，我们可以返回：NOK  


### 7、房态迷你吧
酒店工作人员在客房中拿起电话拨打指定号码，通过IVR语音引导键入相应数据，中间件接收房态或迷你吧数据后，再通过接口发送到酒管系统，ASCⅡ/UTF-8编码发送，格式支持自定义，比如发送哪些字段，字段占位，前后顺序都可以随酒管系统要求灵活配置。  
下面为房态参考样例：  
<span class="blue">H&nbsp;6001&nbsp;01&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;1234&nbsp;&nbsp;</span>    
共22位  
功能码：占2位，以空格后补位  
房间号码：占5位，以空格后补位，样例中的房间号码为6001  
房间状态：占9位，以空格后补位，01代表空可卖，02代表空脏房，03代表空干净，04代表住干净，05代表住脏房，06代表维修房（这些房态内容如和客户酒店需求不同，中间件可以自定义修改）  
员工编号：占6位，以空格后补位  
中间件发送指令后，如需回应返回值的话，酒管可以返回：HOK  
下面为迷你吧参考样例：  
<span class="blue">B&nbsp;6001&nbsp;0036&nbsp;1&nbsp;&nbsp;&nbsp;&nbsp;1234&nbsp;&nbsp;</span>  
共23位  
功能码：占2位，以空格后补位  
房间号码：占5位，以空格后补位，样例中的房间号码为6001  
商品编号：占5位，以空格后补位  
商品数量：占5位，以空格后补位  
员工编号：占6位，以空格后补位  
中间件发送指令后，如需回应返回值的话，酒管可以返回：HOK
